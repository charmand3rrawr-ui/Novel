# Inspiration

Where new creative material comes from, and the guard rails on it.

## `lexicon.json`

The pool the character generator draws from: wounds, lies, masks, competences,
holes, verbal tics, physical signatures, loyalty shapes, fears, moral axes,
offstage lives, arc shapes, entry pretexts.

Edit it by hand any time. Everything in it is original to this project or
generated by the miner below.

## `scrape_characters.py` — mining other novels

```
tools/scrape_characters.py --source pg-1342 --source pg-84
tools/scrape_characters.py --file drafts/my-old-novel.txt --label draft-2019
tools/scrape_characters.py --review
tools/scrape_characters.py --promote all
```

### What it actually does

For every figure it finds in a source, it builds a **behavioural fingerprint**:
which register their speech falls into (forceful, evasive, formal, warm, cold),
which adverbs cling to them (controlled, volatile, performed, withheld), and
which class of action they take (acquisitive, protective, evasive, inquisitive,
assertive, social).

Then it **crosses fingerprints from different sources** and writes the result
through this project's own phrase templates. A candidate atom is a hybrid of
one book's speech register and another book's adverb register, expressed in
language neither book used. That crossing is the point: it is where the
creativity comes from, and it is also why nothing traceable to a single source
survives the process.

### What it will not do

- **It never stores source prose.** Only counts, register labels, and generated
  phrasing.
- **It never reuses source names.** Every detected name goes onto
  `mined.json → avoid_names`, which the character generator reads and steers
  around. It is an exclusion list, not a name bank.
- **It never auto-promotes.** Candidates sit in `mined.json` marked `pending`
  until you review and promote them.

### Sources

Point it only at text you are entitled to analyse: public-domain works, your
own drafts, or licensed material. `sources.json` ships with public-domain
titles; the miner strips Project Gutenberg boilerplate automatically.

## `mined.json`

Working state: the avoid-list, mined fingerprints, candidate atoms with
provenance, and what has been promoted. Provenance survives promotion — every
mined atom in the lexicon records which registers were crossed and which
sources contributed.
